Vernia Spendlint

Up and running in under a minute. Python and TypeScript, no account needed.

  1. Install

    pip install spendlint

  2. Scan your repository

    Run it from the root of any project that calls an LLM.

    spendlint .

  3. Check every pull request

    Add the GitHub Action. It flags only the lines a pull request adds, so old code never gets in the way.

    # .github/workflows/spendlint.yml
on: pull_request
jobs:
  spendlint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: vernialabs/spendlint@v0
